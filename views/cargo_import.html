Bulk Cargo Import

Upload a CSV manifest to import cargo records into the station ledger in bulk. The importer accepts any well-formed file — no authentication token is required beyond your crew session.

CSV format (header row required): 

summary,slug,qty,unit_price
Cycle 414 Cargo Delivery,ration-pack-alpha,10,12
Cycle 414 Cargo Delivery,oxygen-canister-standard,4,45

Rows with the same summary are grouped into a single manifest entry. The slug field must match a commissary product slug. Use Download sample CSV to get a pre-filled export from the current catalog.
