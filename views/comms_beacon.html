Protocol Spec // beacon-mac-v1

The station signs outbound beacons with a homegrown construction. Crews implementing offline verifiers can use the pseudocode below. 

a   = SHA1(secret + "|" + timestamp + "|" + message)
b   = SHA1(timestamp + "|" + message + "|" + secret)
sig = HEX( (a XOR b)[0..10] )

The shared secret is a short station-wide key, rotated quarterly.
